# Airbnb London Pricing and Listing Performance Analysis

## Summary
Analysis of Airbnb listings in London to explore pricing patterns,
neighborhood performance, and factors influencing listing popularity
and occupancy.

## Project Structure
- notebooks/airbnb_london_analysis.ipynb — Main analysis notebook
- data/ — Raw and processed datasets
- images/ — Visualizations and charts

## How to Run
1. Download the dataset from the link in data/README.md
2. Place it in the data/ folder
3. Open notebooks/airbnb_london_analysis.ipynb in Google Colab
4. Run all cells

## Tools Used
- Python, pandas, NumPy
- SQL
- Matplotlib, Seaborn
- Tableau Public / Google Data Studio
